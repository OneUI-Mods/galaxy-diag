# Reliability audit — 2026-11-18

## コマンドの出力を読み取る前に終了を待っている

Drain command output while waiting, with one deadline and a strict capture bound. This prevents large output from filling a pipe and avoids unbounded readText. Apply to both the app root request and qrtr lookup. The DIAG command set and modem behavior are unchanged; only local shell fixtures are exercised.

No feature switches, boot preferences, signing identity, target scopes or Android 16/17 compatibility gates are changed. This is a source fix and regression check, not proof of physical-device behavior. No release APK is distributed by this audit.
