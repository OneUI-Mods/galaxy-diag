# galaxy-diag 0.2.4

機種の制限をなくしました。Galaxy S26 Ultra（SM-S948Q）以外のGalaxyでも、DIAG接続の準備と解除を試せます。Samsungの電話サービスがない端末では、その旨を表示します。動作を確認している端末は引き続きSM-S948Q（Android 17）だけで、機種、OS、モデムによっては接続できない場合があります。

署名済みAPKを上書きして更新してください。

There is no longer a model restriction. Galaxy devices other than the Galaxy S26 Ultra (SM-S948Q) can now try preparing and removing the DIAG connection. Devices without Samsung's telephony service show a message saying so. The SM-S948Q (Android 17) is still the only validated device, and some models, OS versions, or modems may not connect.

Install the signed APK as an update.
