# Galaxy DIAG

Galaxyのモデム測定接続を準備するrootアプリです。アプリを開いた時にDIAG許可を送り、モデムの接続口が使える状態になったことを確認します。「許可してNSGを開く」からNetwork Signal Guruを起動できます。

## 対応環境

- Samsung Galaxy S26 Ultra **SM-S948Q / SM8850 / Android 17**
- 動作するroot環境（KernelSUなど）
- 測定には別途Network Signal Guruが必要です

確認した端末以外では許可通知を送りません。同じ機種でもOS・モデムの更新で動作しなくなる可能性があります。5G NRの実受信と端末再起動後の自動適用は、初版では実機再起動を伴う検証をしていません。起動後の処理と共通のジョブは、実機で閉じた接続を復旧するところまで検証済みです。

## 使い方

1. [Releases](https://github.com/OneUI-Mods/galaxy-diag/releases)の署名済みrelease APKをインストールします。
2. KernelSUなどのroot管理アプリで、**Galaxy DIAGへのroot許可を有効**にします。`su`を非表示にする設定では、先にroot管理アプリ側で許可が必要です。
3. Galaxy DIAGを開きます。接続準備には十数秒かかることがあります。
4. 「MPSS接続を確認しました」と表示されたら「許可してNSGを開く」を押します。

初回の適用成功後は「端末起動後に自動適用」がONになります。以後、端末起動後またはこのアプリの更新後に一度だけ適用します。起動直後に失敗した時の再試行は2回までです。Samsung側が許可を閉じた場合は、このアプリを開いて再適用してください。

「許可を解除」はDIAGを閉じ、端末起動後の自動適用もOFFにします。再びこのアプリを開くと許可を適用します。自動適用を止めたい場合はスイッチをOFFにし、アプリを開かないでください。

## 画面と外観

接続カードで準備状態を確認し、「NSGを開く」から測定を始められます。再適用・状態確認はカード下部、自動適用と解除は設定行にまとめています。右上の情報ボタン→「外観」から、端末に合わせる／ライト／ダークを選べます。

## 電池・プライバシー

常駐サービス、周期的な監視、アプリ独自のネット通信はありません。処理中だけroot補助プロセスを動かし、終了後は停止します。DIAG許可と、NSG自身の測定・ログ収集は別です。測定を終えたらNSG側でも終了してください。DIAGを有効にした状態の長時間の電池消費は未測定です。
